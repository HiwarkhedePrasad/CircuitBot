# CircuitBot: Fix USB-C Pin Merging & Wire Overlap Bugs

## Problem

USB-C connector pins (CC1, CC2, D+, D-, VBUS, GND) are being merged incorrectly. Wires overlap because multiple pins share the same coordinates or get collapsed by name.

## Confirmed Bugs

### Bug 1 (Critical): Pin matcher collapses pins by name

**File:** `agent/pin_matcher.py` lines 315-318

```python
usb_pins = {
    _canonical(pin_matrix[k].get("name", "")): k  # KEYED BY NAME!
    for k in pin_matrix
    if k.split(":")[0] == ref and k not in assigned
}
```

Four VBUS pins (A4/A9/B4/B9) all named "VBUS" → dict keeps only the last one. Other 3 VBUS pins silently lost.

**Fix:** Change to `dict[str, list[str]]` to preserve ALL pins per name.

### Bug 2 (High): VBUS matching breaks after first match

**File:** `agent/pin_matcher.py` line 328

```python
break  # Only one VBUS pin matched!
```

**Fix:** Remove `break`, loop over ALL VBUS pins.

### Bug 3 (High): Hidden power pins share position (0,0)

**File:** `agent/sexpr_utils.py` lines 147-148

Hidden VBUS/GND pins in USB-C have `(at 0 0)` in symbol → all 4 VBUS pins get identical (x,y) coordinates → wires overlap at same point.

**Fix:** Add offset for hidden pins based on their pin number index.

### Bug 4 (Medium): Fallback groups pins globally by name

**File:** `agent/utils.py` lines 276-289

`_generate_nets_fallback` groups ALL leftover pins by name across all components. Can merge pins that should be separate.

**Fix:** Only group pins from different components, or handle power pins specially.

## Plan

### Fix 1: pin_matcher.py — dict keyed by pin_key, not name

Change usb_pins from `{name: pin_key}` to `{name: [pin_key, ...]}` and iterate all pins per name.

### Fix 2: pin_matcher.py — remove break in VBUS loop

Remove the `break` after first VBUS match, iterate all VBUS pins.

### Fix 3: sexpr_utils.py — offset hidden pin positions

For hidden power pins (x=0, y=0), add an offset based on pin number index so they don't all overlap.

### Fix 4: utils.py — don't merge same-component pins by name

In `_generate_nets_fallback`, only group pins from DIFFERENT components.
