## Changes (Single File: `website/index.html`)

### 1. Layout Structure (MiMo Code-style)
- Full-viewport hero, vertically centered content
- **Large circuit board graphic** on the left side (replacing the apsara figure) — generated via Canvas, rendered as a realistic PCB section with traces, IC footprints, pads, vias
- Title "CircuitBot" centered/right-aligned
- Subtitle describing the product
- OS toggle buttons (Linux/macOS | Windows)
- Install command box with copy button (styled like terminal)

### 2. Circuit Board Background (the "hero graphic")
- Canvas-generated realistic PCB section rendered behind/around the title area
- Dark black substrate with white silkscreen traces
- IC footprints with pin-1 markers, SMD pads, vias with annular rings
- Traces route with Manhattan + 45° angles (matching real PCB routing)
- **Hover reveal**: entire board dim by default, mouse proximity lights up traces/pads/vias with white glow — like shining a flashlight on a dark PCB

### 3. Water/Ripple Hover Effect
- Radial glow follows cursor (CSS + JS)
- On hover: traces near cursor smoothly illuminate with soft bloom
- On click: expanding ripple rings radiate outward from click point
- Smooth easing on all transitions

### 4. UI Components
- **OS Toggle**: Pill-shaped toggle with two options, active state highlighted
- **Install Command Box**: Dark terminal-style box with `>_` prompt, monospace font, copy icon button
- **Silkscreen decorations**: PCB edge markings, revision text, mounting holes in corners

### 5. Typography
- Title: Orbitron (techy, circuit-board feel)
- Body/UI: Rajdhani or similar clean geometric sans-serif
- Command box: JetBrains Mono or similar monospace
