# CircuitBot Premium UI Overhaul (Skill-Guided)

## Goal
Transform CircuitBot's frontend from generic dark-theme IDE into a distinctive, premium, hardware-engineering-grade UI. Pure CSS + minimal JS — no new libraries. Logic and flow unchanged.

## Design Direction
**Aesthetic**: Industrial-luxury hardware lab. Copper traces, dark circuit board substrate, ambient glow from "powered on" elements. Think: Altium Designer meets luxury watch UI. NOT another VS Code clone.

**One accent**: Copper (#d98443). Everything else is neutral dark with warm tint. No competing accent colors.

**Typography**: Distinctive, not generic. NO Inter, NO Space Grotesk, NO Roboto.

**Atmosphere**: Grain texture, layered depth, ambient light gradients, spring-based motion.

## Files to Modify
- `static/style.css` — complete visual overhaul
- `static/index.html` — fonts, SVG defs, layout adjustments, empty state
- `static/app.js` — message wrapping with avatars, staggered animations (~4 functions, logic unchanged)
