# Fix Command Autocomplete - Professional Command Palette

## Problem
When typing `/de` and pressing Enter, the raw text is sent to the backend instead of selecting from the autocomplete dropdown. The current implementation has bugs in the keyboard handling logic.

## Root Cause
1. The `activeCommandIndex` starts at -1, causing Enter to not select properly
2. The command mode state isn't tracked correctly
3. Enter key handling conflicts between autocomplete selection and message sending

## Solution: Professional Command Palette

### Files to Modify
- `static/app.js` - Rewrite command autocomplete logic
- `static/style.css` - Add command icon styling
- `static/index.html` - Update command list HTML structure

### New Behavior
1. **Type `/`** → Show all commands in a dropdown
2. **Type `/de`** → Filter to matching commands (`/design`)
3. **Arrow keys** → Navigate through commands
4. **Enter** → Select highlighted command and focus for args
5. **Tab** → Autocomplete command name
6. **Escape** → Close dropdown
7. **Enter again** → Send the message with args

#### Step 2: Rewrite JavaScript Logic
```javascript
const COMMANDS = [
    { name: '/design', desc: 'Full PCB design pipeline', icon: '⚡' },
    { name: '/add', desc: 'Add a component to the board', icon: '+' },

    { name: '/status', desc: 'Show current design status', icon: '●' },
    { name: '/export', desc: 'Export the design', icon: '↓' },
    { name: '/help', desc: 'Show available commands', icon: '?' },
];

let commandMode = false;
let activeCommandIndex = 0;
let filteredCommands = [];

function showCommandPalette() {
    commandAutocomplete.classList.remove('hidden');
    commandMode = true;
    updateFilteredCommands();
}

function hideCommandPalette() {
    commandAutocomplete.classList.add('hidden');
    commandMode = false;
    activeCommandIndex = 0;
}

function executeCommand(cmd) {
    agentPrompt.value = cmd.name + ' ';
    hideCommandPalette();
    agentPrompt.focus();
    updateAgentButton();
}
```
