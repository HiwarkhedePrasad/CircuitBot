# Plan: Flux.ai-Style Context Menu — AI Support, Add/Remove/Replace, Image Insert, Trace Tools

## Vision

Transform the right-click context menu from a simple action list into a Flux.ai-style intelligent design assistant. When the user right-clicks any object, they get:

1. **AI Support** — a floating chat panel where they can ask questions or make requests about the selected object
2. **Add component** — quick-add components from the library
3. **Remove/Replace** — remove or swap the selected component with alternatives
4. **Image insertion** — insert reference images (schematics, datasheets, photos)
5. **Trace tools** — connect/attach traces between components

## What needs to be built

### 1. AI Support Panel (Flux-style floating chat)

A floating panel that appears when you click "Ask AI about this" in the context menu. It has:
- A chat input field at the bottom
- Message history in the body
- Sends messages via Socket.IO with context about the selected object
- Receives AI responses in real-time

**Files to modify:**
- `static/pcb_view/events.js` — Add `pcbShowAISupportPanel(entityType, entityId)` function
- `static/pcb_view/events.js` — Add "Ask AI about this" to context menu for components, traces, and nets

**Panel structure:**
```html
<div id="pcbAISupportPanel">
  <div class="header">AI Support — [Component: U1]</div>
  <div class="messages">
    <!-- Chat messages appear here -->
  </div>
  <div class="input-area">
    <input type="text" placeholder="Ask about this component..." />
    <button>Send</button>
  </div>
</div>
```

**Backend:** No new endpoint needed — uses existing `chat:message` Socket.IO event with context prefix:
```
[Context: Component U1 (ESP32-WROOM-32D) on net VCC_3V3] user question here
```

### 3. Remove/Replace Component

**Files to modify:**
- `static/pcb_view/events.js` — Add "Remove this component" and "Replace with..." to component context menu
- `static/pcb_view/events.js` — Add `pcbRemoveComponent(ref)` and `pcbShowReplacePanel(ref)` functions
- `server/routes.py` — Add `/api/direct_modify` endpoint for direct modifications (skip LLM classification)

**Flow for Remove:**
1. User right-clicks component → "Remove this component"
2. Frontend calls `/api/direct_modify` with `{modification_type: "remove_component", target: {ref}}`
3. Backend removes from selected_components, board_model, nets
4. Frontend updates pcbState.boardModel and re-renders

**Flow for Replace:**
1. User right-clicks component → "Replace with..."
2. Frontend calls `/api/object_knowledge` to get alternatives
3. Shows alternatives panel with pick buttons
4. User picks one → frontend calls `/api/swap_component` with `{ref_des, new_id_str}`
5. Backend resolves footprint/pins and updates component
6. Frontend updates pcbState.boardModel and re-renders

### 4. Image Insertion

A panel that allows inserting reference images (schematics, datasheet screenshots, photos of real PCBs).

**Files to modify:**
- `static/pcb_view/events.js` — Add "Insert reference image" to empty space context menu
- `static/pcb_view/events.js` — Add `pcbShowImageInsertPanel()` function
- `static/pcb_view/editor_webgl.js` — Add image overlay rendering in the Canvas2D overlay
- `static/pcb_view/state.js` — Add `referenceImages: []` to pcbState

**Panel structure:**
```html
<div id="pcbImageInsertPanel">
  <div class="header">Insert Reference Image</div>
  <div class="upload-area">
    Drop image here or click to browse
  </div>
  <div class="options">
    <label>Opacity: <input type="range" min="0.1" max="1" step="0.1" /></label>
    <label>Layer: <select>F.Cu, B.Cu, User</select></label>
  </div>

```

**Image storage:** Images stored as base64 data URLs in pcbState.referenceImages. Rendered as overlays on the PCB canvas.

### 5. Trace Connection Tools

Enhanced trace routing from the context menu.

**Files to modify:**
- `static/pcb_view/events.js` — Add trace-related actions to component context menu

**Actions:**
- "Route to..." — starts routing from this component's nearest pad
- "Connect to [other component]" — routes between two specific components
- "Auto-route all" — triggers auto-routing for the selected net

**Backend:** Uses existing routing infrastructure (pcb_design/router2.py).
