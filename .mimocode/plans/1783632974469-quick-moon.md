# Routing UX Improvements Plan

## Two Features

1. **Auto-snap to pins** - Better auto-adjustment when clicking near a pin during routing
2. **Dim non-connected components** - During routing, dim unrelated components and keep airwires bright

---

## Feature 1: Auto-Snap to Pins

### Current State
- Hit detection uses 0.9mm tolerance (good)
- Route cursor already snaps to pad center on hover
- But clicking slightly off a pad doesn't always connect

### Improvement
Increase the auto-connect radius when the user clicks during routing. If the click is within 1.5mm of a pad, auto-connect to that pad instead of adding a route point.

**File: `static/pcb_view/events.js`**

Update the mouseDown handler during routing (lines 390-414):

**File: `static/pcb_view/utils.js`**

Add new function `findNearbyPad`:
```javascript
function findNearbyPad(screenX, screenY, radiusMm) {
    const world = pcbEditor.screenToWorld(screenX, screenY);
    let best = null;
    let bestDist = radiusMm;
    for (const comp of pcbState.boardModel?.components || []) {
        for (const pad of comp.pads || []) {
            const center = getComponentPadPosition(comp, pad);
            const dist = Math.hypot(world.x - center.x, world.y - center.y);
            if (dist < bestDist) {
                bestDist = dist;
                best = { pad, component: comp, key: `${comp.ref}:${pad.number}`, x: center.x, y: center.y };
            }
        }
    }
    return best;
}
```

## Feature 2: Dim Non-Connected Components During Routing

### Current State
- All components render at full opacity
- No distinction between connected and unrelated components during routing

### Improvement
When actively routing a net:
1. **Dim all components** to 30% opacity
2. **Highlight components connected to the current net** at full opacity
3. **Keep airwires for the current net bright** (already done)
4. **Show connecting traces bright** (already done)

_isComponentConnectedToNet(component, netName) {
    if (!netName) return true;
    for (const pad of component.pads || []) {
        if (pad.net === netName) return true;
    }
    return false;
}

## Verification Plan

### Auto-Snap Test
1. Activate Route tool (R)
2. Click a pad to start routing
3. Move cursor near another pad (within 1.5mm but not exactly on it)
4. Click
5. Verify: Route auto-connects to the nearby pad
6. Verify: No extra route point is added

### Component Dimming Test
1. Load a PCB with multiple components
2. Activate Route tool (R)
3. Click a pad that belongs to "VCC" net
4. Verify: Components connected to VCC remain bright
5. Verify: Other components are dimmed (30% opacity)
6. Verify: Airwires for VCC net are bright cyan
7. Verify: Airwires for other nets are dimmed
8. Complete the route
9. Verify: All components return to full opacity

6. All components return to normal after routing completes
