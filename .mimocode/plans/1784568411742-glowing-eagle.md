## Issues Found in Live Run

### Issue 1: select_node doesn't check _builtin_components
**Symptom**: CP2102N was selected for "Programming & Debug" even though capability_resolver already added a builtin USB-to-UART bridge.
**Root cause**: `select_node` doesn't read `state["_builtin_components"]` to skip subsystems already provided by the board.
**Fix**: Add guard in select_node to skip selection for capabilities already provided by board_type.

### Issue 2: dependency_expander injects wrong MCU module
**Symptom**: WEMOS_C3_mini was injected for "crystal_40mhz" and "decoupling_caps" but conflicts with the selected ESP32-WROOM-32U.
**Root cause**: `get_requirements("ESP32-C3", "devkit")` returns crystal/decoupling requirements, but the actual selected MCU is ESP32-WROOM-32U (ESP32 family, not ESP32-C3). The expander should detect that the selected MCU is a module that already has these.
**Fix**: Before injecting, check if any selected component is a module/MCU that already provides the requirement.

### Issue 3: deduplicator doesn't catch same-family duplicates
**Symptom**: Two TMP117 sensors selected (TMP117xxDRV and TMP117xxYBG) with different subsystems.
**Root cause**: Deduplicator only checks exact id_str match. Different variants of the same IC aren't caught.
**Fix**: Add family-level dedup for non-passive ICs (same base part number = duplicate).

### Issue 4: LLM validate_node still mutates component list
**Symptom**: After constraint_checker + repair passed clean, the old validate_node added USB_C_Receptacle, AMS1117, CP2102N, R2 back.
**Root cause**: The old validate_node has auto-add logic for missing_components that ignores architecture_frozen/board_type.
**Fix**: In the new pipeline, skip the old validate_node's auto-add logic when architecture_frozen=True. Or remove the old validate from the new pipeline entirely.

### Issue 5: Constraint checker doesn't detect MCU module conflicts
**Symptom**: WEMOS_C3_mini was injected alongside ESP32-WROOM-32U without any fatal error.
**Root cause**: `_check_duplicate_mcus` only checks `_is_mcu()` which looks for "MCU" in category or "ESP32" in id_str. WEMOS_C3_mini has category "RF_Module" and id_str "RF_Module:WEMOS_C3_mini" — neither contains "MCU" or "ESP32".
**Fix**: Expand `_is_mcu` to also detect devkit/module MCU entries (WEMOS, NODEMCU, DEVKIT, etc.).

## Fix Plan

### Fix 1: select_node — skip builtin-provided subsystems
**File**: `agent/nodes/select.py`
**Change**: At the start of the per-subsystem loop, check if the subsystem is already provided by builtin components. If so, skip selection for that subsystem.

```python
# After line 337 (for sub in research:):
builtin = state.get("_builtin_components", [])
builtin_subs = {c.get("subsystem", "").replace("builtin_", "") for c in builtin}
if sub_name.lower() in {s.lower() for s in builtin_subs}:
    _emit(config, "agent:log", {"message": f"  Skipping '{sub_name}' — provided by board"})
    continue
```

Also add an avoid_list filter using `board_type` avoid_adding patterns.

### Fix 2: dependency_expander — detect module MCU already selected
**File**: `agent/nodes/dependency_expander.py`
**Change**: Before injecting requirements, check if any selected component is a module/MCU that already satisfies the requirement. Specifically, if a WROOM/DEVKIT/MODULE is selected, skip crystal/decoupling/USB/regulator injections.

```python
# After line 112 (all_comps = builtin + comps):
# Check if selected MCU is already a module that provides its own requirements
selected_is_module = any(
    any(kw in (c.get("id_str", "") or "").upper()
        for kw in ("WROOM", "DEVKIT", "MINI", "MODULE", "NODEMCU", "WEMOS"))
    for c in comps
)
if selected_is_module:
    # Module already has crystal, flash, etc. — skip dependency injection
    requirements = {}
```

### Fix 3: deduplicator — same-family dedup for ICs
**File**: `agent/nodes/deduplicator.py`

### Fix 4: validate_node — skip auto-add when architecture frozen
**File**: `agent/nodes/validate.py`
**Change**: In the missing_components auto-add section (lines 729-817), check `state.get("architecture_frozen")`. If True, skip auto-adding components and only report them as errors.

```python
# Before line 730 (if missing:):
if state.get("architecture_frozen"):
    # Don't auto-add — architecture is locked
    for mc in missing:
        validation_errors.append(f"Missing component (architecture locked): {mc.get('description', '')}")
    missing = []  # Clear so auto-add doesn't run
```

### Fix 5: constraint_checker — expand _is_mcu detection
**File**: `agent/nodes/constraint_checker.py`
**Change**: Expand `_is_mcu` to detect module MCU entries.

```python
def _is_mcu(comp: dict) -> bool:
    id_str = (comp.get("id_str", "") or "").upper()
    category = (comp.get("category", "") or "").upper()
    # Existing checks
    if "MCU" in category or "PROCESSOR" in category or "CPU" in category:
        return True
    if any(kw in id_str for kw in ("ESP32", "STM32", "RP2040", "RP2350", "ATMEGA", "ATTINY")):
        return True
    # NEW: detect module MCU entries
    if any(kw in id_str for kw in ("WEMOS", "NODEMCU", "DEVKIT", "WROOM")):
        return True
    if "RF_MODULE" in category and any(kw in id_str for kw in ("ESP32", "C3", "S3", "C6")):
        return True
    return False
```
