# CircuitBot UX Improvement Plan

Based on a thorough audit of the frontend UI, PCB editor, and chat/agent interaction.

---

## Priority 1: Critical (Blocks Basic Workflow)

### 1.1 Fix broken zoom level display
- **Problem**: `#zoomLevel` span (index.html:107) always shows "100%" — never updated
- **Fix**: In `pcbZoomBy()` (events.js:84) and wheel handler (events.js:276), write `document.getElementById('zoomLevel').textContent = Math.round(pcbState.zoom * 100) + '%'`
- **File**: `static/pcb_view/events.js`

### 1.2 Fix coordinate display
- **Problem**: `#coordDisplay` (index.html:141) exists but is never updated from mouse position
- **Fix**: In `pcbHandleMouseMove()` (events.js:404), after computing `world`, write to `coordDisplay`
- **File**: `static/pcb_view/events.js`

### 1.3 Add Delete key for components/traces/vias
- **Problem**: No way to delete anything — no keyboard shortcut, no context menu
- **Fix**: Add `Delete`/`Backspace` handler in `pcbHandleKeyDown()`. For selected component: remove from `boardModel.components`, refresh airwires, save. For hovered via: remove from `boardModel.vias`.
- **File**: `static/pcb_view/events.js`

### 1.4 Add component rotation
- **Problem**: No UI or keyboard shortcut to rotate components
- **Fix**: Add `Ctrl+R` / `R` (when not routing) to rotate selected component by 90°. Update `component.rotation`, refresh, save.
- **File**: `static/pcb_view/events.js`

### 1.5 Fix textarea auto-resize
- **Problem**: Chat textarea is `rows="1"` with no auto-resize — multi-line input is invisible
- **Fix**: Add `input` event listener that sets `textarea.style.height = 'auto'` then `textarea.style.height = textarea.scrollHeight + 'px'`
- **File**: `static/app.js`

### 1.6 Fix CSS typing-dots animation
- **Problem**: `.conv-progress::after` uses CSS `content` animation which doesn't work in modern browsers
- **Fix**: Replace with a real DOM element (3 spans) animated via keyframes on `opacity`/`transform`
- **File**: `static/style.css`, `static/app.js`

### 1.7 Fix global keyboard handler eating input
- **Problem**: PCB keyboard shortcuts fire when typing in chat textarea or route input
- **Fix**: Add guard: `if (e.target.tagName === 'TEXTAREA' || e.target.tagName === 'INPUT') return;` at top of keydown handler
- **File**: `static/pcb_view/events.js`

## Priority 2: High Impact (Significantly Improves UX)

### 2.1 Add component hover highlight
- **Problem**: `hoveredComponentRef` is declared but never set during mouse move
- **Fix**: In `pcbHandleMouseMove()`, call `hitTestComponent()` and set `pcbState.hoveredComponentRef`. In `_renderOverlay()`, draw a subtle border/glow for hovered (not selected) components.
- **Files**: `static/pcb_view/events.js`, `static/pcb_view/editor_webgl.js`

### 2.2 Add keyboard shortcut help overlay
- **Problem**: No way to discover shortcuts — users must read source code
- **Fix**: Add `?` key handler that shows a modal/overlay listing all shortcuts (H=Pan, S=Select, R=Route, V=Via, O=Outline, Del=Delete, Ctrl+R=Rotate, Shift+F=Fit, Ctrl+Z/Y=Undo/Redo, Esc=Cancel)
- **Files**: `static/pcb_view/events.js`, `static/index.html`, `static/style.css`

### 2.3 Add clickable suggestion chips for onboarding
- **Problem**: Empty chat shows one line of text — no examples, no quick actions
- **Fix**: When conversation is empty, show 4-6 clickable suggestion chips: "Design a USB power supply", "Add an LED with resistor", "Design a sensor board", "Help"
- **Files**: `static/index.html`, `static/app.js`, `static/style.css`

### 2.4 Add connection status indicator
- **Problem**: Socket disconnect is silent after initial log line
- **Fix**: Add a small dot/icon in the header or status bar that turns red on disconnect, green on connect. Use socket `connect`/`disconnect` events.
- **Files**: `static/index.html`, `static/app.js`, `static/style.css`

### 2.5 Fix Ctrl+S to save without download
- **Problem**: Ctrl+S saves AND triggers a file download — unexpected
- **Fix**: Ctrl+S should only call `pcbEditor.saveBoardModel()` + show toast. Move download to a separate "Export" button.
- **File**: `static/pcb_view/events.js`

### 2.6 Add markdown rendering for agent messages
- **Problem**: Server sends `**bold**` and bullet points, rendered as literal asterisks
- **Fix**: Add a lightweight markdown-to-HTML converter (bold, italic, code, bullets). Use `innerHTML` with sanitization or a small library.
- **File**: `static/app.js`

### 2.7 Add snap-to-grid cursor indicator during routing
- **Problem**: Routing cursor snaps silently — user can't see where trace will land
- **Fix**: Draw a small crosshair or dot at the snapped grid point in `_renderOverlay()` when in ROUTE mode
- **File**: `static/pcb_view/editor_webgl.js`

### 2.8 Add route info display during routing
- **Problem**: No indication of net name, trace width, or route length while routing
- **Fix**: Show a floating tooltip near the cursor with net name + current route length during ROUTE mode
- **Files**: `static/pcb_view/events.js`, `static/pcb_view/editor_webgl.js`

### 2.9 Add component search (Ctrl+F)
- **Problem**: No way to find a component by ref designator on the board
- **Fix**: Add Ctrl+F handler that shows a search input. Matching component gets zoomed-to and highlighted.
- **Files**: `static/pcb_view/events.js`, `static/pcb_view/editor_webgl.js`, `static/index.html`

### 2.10 Fix zoom buttons styling
- **Problem**: Zoom buttons (-, +, Fit) have zero CSS — render as default browser buttons
- **Fix**: Add CSS rules for `.zoom-group button` with dark theme styling matching other tool buttons
- **File**: `static/style.css`

## Priority 3: Medium Impact (Polish & Refinement)

### 3.1 Add hover states on all interactive elements
- **Problem**: Tabs, tool buttons, zoom buttons, icon buttons missing `:hover`/`:active`/`:focus-visible`
- **Fix**: Add consistent hover (background shift), active (scale 0.98), focus-visible (outline) to all buttons
- **File**: `static/style.css`

### 3.2 Add timestamps to chat messages
- **Problem**: No time context for messages
- **Fix**: Show relative time ("2m ago") or absolute time next to each message
- **File**: `static/app.js`, `static/style.css`

### 3.3 Add toast notification system
- **Problem**: All feedback goes into conversation stream — no transient notifications
- **Fix**: Add a small toast container (bottom-right). Show toasts for: save success, export complete, disconnect, errors.
- **Files**: `static/index.html`, `static/app.js`, `static/style.css`

### 3.4 Add error message visual distinction
- **Problem**: Errors blend into conversation — no icon, no background
- **Fix**: Add red left-border + warning icon + "Error:" prefix to error messages
- **File**: `static/style.css`, `static/app.js`

### 3.5 Improve proposal cards with footprint info
- **Problem**: Proposals only show component name — no footprint, pin count, package
- **Fix**: Show footprint name, pin count, and package type in the proposal card body
- **File**: `static/app.js`

### 3.6 Add minimap/overview panel
- **Problem**: No way to see full board context while zoomed in
- **Fix**: Add a small canvas in bottom-right corner showing full board with viewport rectangle
- **Files**: `static/pcb_view/editor_webgl.js`, `static/index.html`, `static/style.css`

### 3.7 Fix dead UI elements
- **Problem**: Search feature broken (JS references elements not in HTML), dead CSS for `.properties-view`, dead JS vars `agentPulse`/`agentDot`
- **Fix**: Either implement the search feature or remove the dead code. Remove unused CSS/JS.
- **Files**: `static/app.js`, `static/style.css`, `static/index.html`

### 3.8 Fix status bar color
- **Problem**: Bright blue status bar (`var(--accent)`) dominates the dark theme
- **Fix**: Use a subtle dark background with muted text, or use accent color only for active status
- **File**: `static/style.css`

### 3.9 Add right-click context menu
- **Problem**: Right-click behavior is inconsistent across modes
- **Fix**: In Select mode, right-click on component shows: Rotate, Delete, Properties. Right-click on empty: Paste, Zoom to Fit.
- **Files**: `static/pcb_view/events.js`, `static/index.html`, `static/style.css`

### 3.10 Fix spacing and border-radius consistency
- **Problem**: Inconsistent spacing (4/5/6/8/10/12px) and border-radius (0/2/4/6px)
- **Fix**: Establish design tokens: `--space-xs: 4px`, `--space-sm: 8px`, `--space-md: 12px`, `--space-lg: 16px`. Use `--radius-sm: 4px`, `--radius-md: 6px`, `--radius-lg: 8px`.
- **File**: `static/style.css`
