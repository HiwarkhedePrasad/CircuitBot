# PCB Board Selection Bug Fix

## Root Cause

The PCB board selection (layer count) is not working because of a race condition in the event handling:

1. When user clicks "Proceed to PCB" button, `handle_pcb_approve` in `ws_handlers.py` **pops** the entry from `_agent_events` (line 54)
2. The agent routes to `ask_board_config` node which emits `agent:board_config` with layer options
3. Frontend shows layer buttons (2-Layer, 4-Layer, etc.)
4. When user clicks a layer button, `handle_board_config` tries to get the entry from `_agent_events` (line 74), but it was already **popped** in step 1
5. Result: `entry` is `None`, the event is never set, and the agent hangs forever

## Fix

**File: `server/ws_handlers.py`**

Change `handle_pcb_approve` to NOT pop the entry. Instead, only set the event and result, keeping the entry in `_agent_events` so that `handle_board_config` can still access it later:

```python
@socketio.on('agent:pcb_approve')
def handle_pcb_approve(data):
    entry = _agent_events.get(request.sid)  # Changed from .pop() to .get()
    if entry:
        entry["result"]["approved"] = data.get("approved", False)
        entry["event"].set()
```
