# Plan: No-Connect Flag (X Markers) for Unconnected Pins

## Goal
Mark unconnected pins with an X symbol on the schematic view and in KiCad .kicad_sch export, matching the industry-standard convention used by KiCad, Altium, Eagle, and OrCAD.

## Background
- **KiCad format**: `(no_connect (at X Y) (uuid "UUID"))` S-expression entries suppress `pin_not_connected` ERC errors
- **Industry standard**: All major EDA tools use an X-shaped marker at the pin tip for intentionally unconnected pins
- **CircuitBot gap**: Pins are drawn identically whether connected or not. The ERC runner detects `pin_not_connected` errors but the export never emits `(no_connect ...)` entries

## Changes

### 1. Frontend: Draw X markers at unconnected pins

**File: `static/schematic_renderer.js`**

Modify `_renderTerminals()` (line 1381) to check if each pin is connected before drawing:

- Build a `connectedPins` Set from `this._schematic.wirePaths` by collecting all `source` and `target` pin keys
- For each pin in `_pinHitTargets`:
  - If pin.key is in `connectedPins` → draw the existing circle terminal (current behavior)
  - If pin.key is NOT in `connectedPins` → draw an X marker (two crossing lines, ~0.8mm arm length)
- X color: use `SCH_COLORS.wire` (the existing wire color) or a new `SCH_COLORS.noConnect` constant (suggest `#cc4444` red-ish, matching KiCad's convention)

**Specific changes:**
1. Add `noConnect: 0xcc4444` to `SCH_COLORS` in `static/schematic_renderer.js` (near line 10)
2. In `_renderTerminals()`, replace the loop body with:
```js
const connectedPins = new Set();
if (this._schematic) {
    for (const w of this._schematic.wirePaths) {
        if (w.source) connectedPins.add(w.source);
        if (w.target) connectedPins.add(w.target);
    }
}
for (const pin of this._pinHitTargets) {
    if (connectedPins.has(pin.key)) {
        // Connected: draw terminal circle (existing behavior)
        g.lineStyle(0.12, SCH_COLORS.terminal, 0.85);
        g.beginFill(SCH_COLORS.bg, 0.95);
        g.drawCircle(pin.x, pin.y, 0.72);
        g.endFill();
        g.beginFill(SCH_COLORS.terminal, 0.9);
        g.drawCircle(pin.x, pin.y, 0.28);
        g.endFill();
    } else {
        // Unconnected: draw X marker
        const arm = 0.8;
        g.lineStyle(0.2, SCH_COLORS.noConnect, 0.9);
        g.moveTo(pin.x - arm, pin.y - arm);
        g.lineTo(pin.x + arm, pin.y + arm);
        g.moveTo(pin.x + arm, pin.y - arm);
        g.lineTo(pin.x - arm, pin.y + arm);
    }
}
```

### 2. Backend: Generate `(no_connect ...)` in KiCad export

**File: `agent/kicad_export.py`**

After the wire collection phase (around line 560, before `out.append('  (sheet_instances ...)`)`, add a new section:

- Iterate over all pins in `pin_sheet_positions`
- For each pin NOT in `surviving_wired_pins` (already computed at line 404):
  - Emit `(no_connect (at X Y) (uuid "UUID"))` using the pin's sheet coordinates
  - Use `_fmt()` for coordinates and `_new_uuid()` for UUID

```python
# ── no-connect flags for unconnected pins ──
for pin_key, (nc_x, nc_y) in pin_sheet_positions.items():
    if pin_key not in surviving_wired_pins:
        out.append(f'  (no_connect (at {_fmt(nc_x)} {_fmt(nc_y)}) (uuid {_q(_new_uuid())}))')
```

This uses the existing `pin_sheet_positions` dict (built at lines 372-398) and `surviving_wired_pins` set (built at line 404). No new data structures needed.

### 3. ERC: No additional changes needed

The existing ERC handling already suppresses `pin_not_connected` errors for pins not assigned to any net (in `agent/nodes/schematic_audit.py` lines 170-183). With the `(no_connect ...)` entries now in the exported .kicad_sch, KiCad's own ERC will also suppress these errors.
