# Plan: Fix NE555 Timer Circuit Pipeline Failure

## Root Cause

The entire design pipeline is built on the assumption that **every circuit needs a microcontroller**. When a user asks for a NE555 astable timer (a purely analog IC with resistors and capacitors), the pipeline has no concept of "this circuit does not need an MCU" and forces ESP32-C3 into the design, causing cascading failures.

## Failure Chain (5 independent flaws)

| Stage | File | What Happens | Why It's Wrong |
|---|---|---|---|
| **clarify** | `agent/nodes/clarify.py` | Asks "What MCU platform?" with ESP32/RP2040/STM32 options | No concept that some circuits are analog-only; MCU is always treated as a required dimension |
| **analyze** | `agent/nodes/analyze.py` | Template matching fails (no NE555 template), keyword fallback hardcodes MCU+Sensor subsystem, or LLM injects "Microcontroller" because system prompt says to include "processing" | Template library has zero analog/IC-based circuit templates; system prompt assumes every circuit needs processing |
| **analyze (auto-inject)** | `agent/nodes/analyze.py:179-192` | If any `_IMPLIES_MCU` subsystem exists (e.g., "Status Indicator"), MCU is auto-injected | No concept of circuits where the IC itself IS the controller |
| **architecture_planner** | `agent/nodes/architecture_planner.py:127` | Defaults to `primary_mcu = "ESP32-C3"` unconditionally | Hardcoded default with no exit path for non-MCU circuits |
| **state** | `agent/state.py` | `primary_mcu` field is required in AgentState, no field for "no MCU needed" or "circuit_type" | Data model assumes every design has an MCU |

## The Fix

### 1. Add circuit type detection to `agent/state.py`

Add new fields to `AgentState`:
```python
circuit_type: Literal["mcu_based", "ic_based", "analog_only", "mixed"]
primary_ic: str | None  # e.g., "NE555", "LM358", "LM7805"
requires_mcu: bool
```

### 2. Fix `agent/nodes/clarify.py`

- Add a concept of "circuit type" detection before asking questions
- If the prompt mentions a specific IC (NE555, LM358, LM741, etc.), recognize it as IC-based and skip MCU questions
- Add new keyword groups: `timer_ic`, `opamp`, `regulator`, `discrete_analog`
- When circuit type is `ic_based` or `analog_only`, skip MCU/processor dimensions entirely
- Ask relevant questions instead: "What is the target frequency?", "What load current?", etc.

### 3. Fix `agent/nodes/analyze.py`

- Add analog/IC-based templates to `circuit_templates.json`: "555_timer_astable", "opamp_amplifier", "linear_regulator", "discrete_logic"
- Modify the keyword fallback to NOT default to MCU+Sensor for unknown circuits
- Remove or gate the `_IMPLIES_MCU` auto-injection with a circuit type check
- Update `ANALYZE_SYSTEM` prompt to include guidance: "Some circuits are purely analog or IC-based and do not need a microcontroller"

### 4. Fix `agent/nodes/architecture_planner.py`

- Remove the unconditional `primary_mcu = "ESP32-C3"` default at line 127
- Add circuit type awareness: if `requires_mcu == false`, skip MCU selection entirely
- Set `primary_ic` instead of `primary_mcu` for IC-based circuits
- For non-MCU circuits, set `board_type` based on the IC (e.g., "bare_ic" for through-hole IC)

### 5. Fix `agent/prompts.py`

- Update `CLARIFY_SYSTEM` prompt to include: "Determine if this is an MCU-based, IC-based, or analog-only circuit before asking questions"
- Update `ANALYZE_SYSTEM` prompt to include: "Do not assume every circuit needs a microcontroller. Some circuits use dedicated ICs (timers, op-amps, regulators) and do not need an MCU."

### 6. Fix `agent/nodes/validate.py`

- Add validation rule: if `requires_mcu == false` and an MCU is in the component list, flag it as an error
- Add validation rule: if prompt names a specific IC (NE555) and selected component is not that IC, flag as error (this already partially works but triggers too late)

## Files to Modify

1. `agent/state.py` — Add `circuit_type`, `primary_ic`, `requires_mcu` fields
2. `agent/nodes/clarify.py` — Add circuit type detection, skip MCU questions for IC-based circuits

7. `circuit_templates.json` — Add NE555 timer and other analog circuit templates
