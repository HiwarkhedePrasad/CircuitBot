# Plan: Manual Component Add + Right-Click Context Menu with Image Markers

## Overview

Two new features for CircuitBot's schematic editor:
1. **Manual Component Add** — A search-and-add section below the "Placed Components" list in the sidebar
2. **Right-Click Context Menu** — On the canvas, with "Add Screenshot/Photo" as a marker feature

---

## Feature 1: Manual Component Add Section

### What it does
Below the `#componentList` in the "Placed Components" panel, add a collapsible section with:
- A search input that queries the RAG backend (`/api/search`)

## Feature 2: Right-Click Context Menu + Image Markers

### What it does
Right-clicking on the schematic canvas shows a context menu with options:
- **Add Screenshot/Photo** — Opens a file picker for images, places a marker at the click position
- **Add Note** — (optional future) Add a text note marker
- **Paste Image** — (from clipboard)

Image markers are rendered as:
- A small thumbnail on the canvas (PixiJS Sprite from a base64 data URL)
- Clickable to open a larger preview panel
- Draggable to reposition
- Removable via context menu or detail panel

### Data model (in-memory only, no backend persistence)

Markers live in the `Schematic.imageMarkers` array and are lost on page refresh. No backend changes needed.

Add a new class `ImageMarker` to `static/schematic.js`:
```js
class ImageMarker {
    constructor(id, x, y, imageDataUrl, label, width, height) {
        this.id = id;
        this.x = x;            // world coords
        this.y = y;
        this.imageDataUrl = imageDataUrl;  // base64 data URL
        this.label = label || '';
        this.width = width || 20;   // world units
        this.height = height || 15;
    }
}
```

Add `imageMarkers` array to `Schematic` class, plus `addImageMarker()`, `removeImageMarker()` methods.

### Image marker rendering in SchematicRenderer
```js
_renderImageMarkers() {
    if (!this._schematic) return;
    for (const marker of this._schematic.imageMarkers) {
        const sprite = PIXI.Sprite.from(marker.imageDataUrl);
        sprite.anchor.set(0.5);
        sprite.position.set(marker.x, -marker.y);  // Y-flip
        sprite.width = marker.width;
        sprite.height = marker.height;
        this._imageMarkerLayer.addChild(sprite);
        // Store hit target
        this._imageMarkerHitTargets.push({ marker, sprite });
    }
}
```

### File reading approach
Use `FileReader.readAsDataURL()` to convert uploaded images to base64, then store directly in the ImageMarker. For large images, resize to a max dimension (e.g., 800px) before storing to keep memory reasonable.
